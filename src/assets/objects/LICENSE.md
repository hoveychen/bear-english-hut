# 物品素材来源

本目录下的 `*.svg` 全部来自 **OpenMoji**（<https://openmoji.org>），
授权协议 **CC BY-SA 4.0**：<https://creativecommons.org/licenses/by-sa/4.0/>

- 获取脚本：`scripts/fetch-objects.sh`（记录了每个文件名对应的 Unicode 码位）
- 文件未经修改，保持 OpenMoji 原始的 `0 0 72 72` viewBox

角色素材（小熊）**不在**此列：它是本项目手绘的 SVG，见 `src/components/Bear.tsx`；
毯子、餐桌等没有对应 emoji 的道具同样为手绘，见 `src/components/HandDrawn.tsx`。

分发本应用时请保留本文件，以满足 CC BY-SA 的署名要求。
